Во второй практической было реализовано 3 этапа, включающие: CLI-инструмент для анализа графа зависимостей NuGet пакетов. Этап 1: конфигурация через параметры командной строки с валидацией. 
Этап 2: получение прямых зависимостей из NuGet репозитория без использования менеджеров пакетов. 
Этап 3: построение полного графа зависимостей с помощью BFS с поддержкой ограничения глубины, фильтрации, обработки циклов и тестового режима с файловыми репозиториями.
